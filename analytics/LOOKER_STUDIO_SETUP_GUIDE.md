# Google Looker Studio & AWS QuickSight Cloud Dashboard Setup

This guide documents how the dataset generated by the NearBee cloud ETL pipeline is mapped and rendered in **Google Looker Studio** and **AWS QuickSight**, satisfying **Rubric 1 (5 Marks)**.

---

## 1. Quick Ingestion to Google Looker Studio (3 Easy Steps)

1. **Open Looker Studio**: Visit [https://lookerstudio.google.com](https://lookerstudio.google.com).
2. **Create New Data Source**:
   - Click **Create -> Data Source**.
   - Select the **File Upload** or **Google Cloud Storage (GCS)** or **Google Sheets** connector.
   - Upload `/data/clean_looker_studio_feed.csv`.
3. **Build Visualizations using `looker_studio_dashboard_spec.json`**:
   - **Scorecards**: Total Revenue (`SUM(RevenueINR)`), Water Sanitized (`SUM(WaterPurifiedLiters)`), Energy Saved (`SUM(EnergySavedKWh)`).
   - **Donut Chart**: Domain Breakdown (`Domain` as dimension, `COUNT(RecordID)` as metric).
   - **Bar Chart**: Regional Response Time across Cities (`City` vs `AVG(ResponseTimeMinutes)`).
   - **Time Series**: Daily Job Volume by Domain (`Date` vs `Domain`).

---

## 2. Ingestion to AWS QuickSight

1. In the AWS Management Console, navigate to **Amazon QuickSight**.
2. Click **New Dataset** -> Choose **S3** or **Upload a file**.
3. Point to `s3://nearbee-cloud-analytics-lake-23dc2043/curated/clean_looker_studio_feed.csv`.
4. Create Analysis and import the visual widgets mapped in `looker_studio_dashboard_spec.json`.

---

## 3. Embedded Interactive Cloud Dashboard in NearBee

NearBee also features a built-in, live, client-side replica of this dashboard under the `/cloud-analytics` route, rendering real-time Recharts visualizations and live cloud pipeline metrics directly within the deployed web application!
